NOIR MARKET

Политика конфиденциальности

Дата публикации: 13 октября 2026 года

Настоящая политика объясняет, какие данные могут обрабатываться при использовании NOIR MARKET через Telegram и веб-приложение. Используя сервис, пользователь должен ознакомиться с настоящим документом.

NOIR MARKET должен обрабатывать только данные, необходимые для работы сервиса. Фактические процессы хранения и передачи данных должны соответствовать описанным ниже правилам.

1. Какие данные могут обрабатываться

В зависимости от используемых функций сервиса могут обрабатываться:

  • Telegram ID, необходимый для идентификации пользователя;
  • имя пользователя Telegram, если оно доступно и требуется для функции;
  • содержимое корзины и выбранные пользователем товары;
  • технические сведения, необходимые для обеспечения безопасности;
  • обращения в поддержку и сведения, которые пользователь сам передал.

2. Для чего используются данные

Данные могут использоваться для следующих целей:

  • отображения и сохранения персональной корзины;
  • работы функций каталога и пользовательского интерфейса;
  • обработки запросов пользователя;
  • защиты от злоупотреблений и несанкционированного доступа;
  • выполнения применимых юридических обязательств.

3. Корзина и хранение информации

Если серверное сохранение корзины включено, её содержимое связывается с Telegram ID пользователя, чтобы разные пользователи не получали доступ к корзинам друг друга.

Срок хранения данных должен быть ограничен временем, необходимым для работы соответствующей функции, либо применимыми юридическими требованиями. Владелец сервиса должен определить и реализовать конкретные сроки хранения перед запуском.

4. Передача третьим сторонам

Для работы сервиса могут использоваться инфраструктура Telegram, хостинг приложения и база данных. Такие поставщики могут обрабатывать технические данные в пределах, необходимых для предоставления услуг.

Данные не должны продаваться третьим сторонам. Любая дополнительная передача данных должна иметь законное основание и быть ограничена необходимой целью.

5. Безопасность

Для защиты информации следует использовать HTTPS, ограничивать доступ к базе данных, проверять подлинность данных Telegram Mini Apps, применять серверную проверку запросов и хранить секреты в переменных окружения. Токены и ключи доступа нельзя помещать в публичный код.

6. Права пользователя

Пользователь может запросить информацию об обработке своих данных, исправление неточных сведений или удаление данных, если это допускается применимым законодательством.

Для обращения по вопросам конфиденциальности используй контакт владельца сервиса, опубликованный в официальном Telegram-боте. До публикации политики владелец должен указать действующий контакт.

7. Дети

Сервис не должен использоваться в нарушение возрастных ограничений и правил Telegram. Если для определённых функций требуется согласие законного представителя, оно должно быть получено в соответствии с применимым законодательством.

8. Изменения политики

Политика может обновляться при изменении функциональности сервиса, способов обработки данных или применимых требований. Актуальная версия публикуется на этой странице с обновлённой датой.

9. Контактная информация

По вопросам обработки данных обращайся к владельцу NOIR MARKET через официальный канал поддержки сервиса. Перед запуском необходимо указать здесь реальный контакт для обращений.
